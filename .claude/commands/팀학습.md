실행 옵션: $ARGUMENTS
(예: all(기본), source, domain, tc, history)

## 목적

프로젝트 완료 후(TC 리뷰 이후) 소스 분석 노하우, 도메인 지식, TC 작성 패턴을 추출하여 **지속 학습 저장소**(`/Users/Claude/ProjectQA/_agent_learning/`)에 축적합니다. 다음 프로젝트에서 이 학습을 자동 로드하여 1차 TC 품질을 향상시킵니다.

## 전제 조건

- TC 리뷰(`/TC리뷰` 또는 수동 리뷰)가 완료되어 있을 것
- `_summaries/` 에 도메인별 요약 파일이 존재할 것
- `_tc_data/` 에 TC 데이터 파일이 존재할 것

## 실행 절차

### Step 1: 현재 프로젝트 정보 수집

1. CLAUDE.md에서 프로젝트명, 투입 에이전트 목록 읽기
2. `_summaries/` 파일 목록 확인
3. `_tc_data/` 파일 목록 확인
4. TC 리뷰 결과(있으면) 확인

### Step 2: 소스 분석 노하우 추출 (source_specialists/)

각 소스 타입별로 이번 프로젝트에서 새로 발견한 분석 패턴을 추출합니다.

**추출 대상** (도메인별 요약 파일에서):
- 소스 구조 패턴: 와디즈 특화 구조, 페이지 배치 규칙
- 추출 효율화 팁: 어떤 순서로 분석하면 효과적이었는지
- 주의사항: 누락하기 쉬운 요소, MCP 도구의 한계
- 도구 활용법: MCP 도구 사용 시 효과적인 패턴

**업데이트 방법**:
1. 기존 `source_specialists/{source}.md` 파일 읽기
2. 이번 프로젝트 요약에서 새로운 노하우 식별
3. 기존 내용과 중복되지 않는 신규 학습만 **추가**
4. 학습 이력 테이블에 프로젝트 엔트리 추가
5. "와디즈 특화 지식" 섹션에 구체적 사실 추가

### Step 3: 도메인 지식 추출 (domain_experts/)

각 투입 에이전트의 도메인 지식을 추출합니다.

**추출 소스** (도메인별):
- `_summaries/{agent-id}/coverage_matrix.md` → 비즈니스 규칙, 상태 머신
- `_summaries/{agent-id}/cross_analysis.md` → 소스 간 불일치, 크로스 도메인 접점
- `_agents/{agent-id}/business_rules.md` → DKB에 축적된 규칙
- `_agents/{agent-id}/state_machines.md` → 상태 머신

**업데이트 방법**:
1. 기존 `domain_experts/{domain}.md` 파일 읽기 (없으면 신규 생성)
2. 이번 프로젝트에서 확인된 비즈니스 규칙, 상태 머신, 경계값 추출
3. 기존 내용과 비교:
   - 신규 발견 → 추가
   - 기존 내용 정정 → 업데이트 (이전 내용 삭제하지 말고 "수정됨" 표기)
   - 반복 확인 → 확신도 상승 (예: "(확인됨)" → "(2회 확인)")
4. 학습 이력 테이블에 프로젝트 엔트리 추가

## 학습 품질 기준

| 기준 | 설명 |
|------|------|
| 구체성 | 추상적 교훈이 아닌, 구체적 사실/수치/예시 포함 |
| 재활용성 | 다음 프로젝트에서 실제로 적용 가능한 내용 |
| 비중복 | 기존 학습과 중복되지 않는 신규 내용만 추가 |
| 정확성 | 소스에서 확인된 사실만 기록 (R1 적용) |
| 간결성 | 핵심만 기록, 불필요한 설명 제외 |

## Override 규칙

학습 저장소의 내용은 **과거 경험 기반의 가이드**입니다:
- **현재 프로젝트 소스 > 과거 학습**: 현재 소스에서 확인된 사실이 과거 학습과 다르면, 현재 소스가 우선
- **학습 수정**: 과거 학습이 잘못된 것으로 확인되면, 학습 파일을 수정(삭제가 아닌 정정)

## 주의사항

- 학습 추출은 TC 리뷰 완료 후 실행 권장 (리뷰 피드백이 가장 가치 있는 학습 소스)
- 프로젝트별 DKB(_agents/)는 그대로 유지 — 학습 저장소는 DKB의 "졸업" 버전
- 학습 파일이 과도하게 커지면(500줄 이상) 핵심만 남기고 정리
- 도메인 전문성 파일은 최대 15개까지 확장 가능 (와디즈 도메인 수)
