# /팀배포 - 에이전트팀 초기 설정

투입할 도메인 에이전트를 지정하세요: $ARGUMENTS
(예: funding,user,maker 또는 all)

## 목적

프로젝트에 투입할 도메인 에이전트를 설정하고, 각 에이전트의 DKB(도메인 지식 베이스) 디렉토리를 초기화합니다.

## 전제 조건

- `설정_소스경로.md`에 프로젝트 소스 URL이 설정되어 있을 것
- CLAUDE.md에 프로젝트 개요가 작성되어 있을 것
- `설계_에이전트팀_아키텍처.md`의 도메인 목록(2.1절) 참조

## 사용 가능한 Agent ID

| Agent ID | 도메인 |
|----------|--------|
| home | 메인홈/전시 |
| funding | 펀딩/프로젝트 |
| maker | 메이커 서비스 |
| user | 회원/인증 |
| payment | 결제/정산 |
| notification | 알림 서비스 |
| ad | 광고센터 |
| community | 커뮤니티/소셜 |
| search | 통합검색 |
| wish | 위시/찜하기 |
| exhibition | 통합기획전 |
| global | 글로벌 |
| crm | CRM/마케팅 |
| admin | 어드민 |
| wai | WAi (AI) |

## 실행 절차

### Step 1: 인자 파싱

1. `$ARGUMENTS`를 쉼표로 분리하여 Agent ID 목록 추출
2. `all` 지정 시 15개 전체 에이전트 선택
3. 유효하지 않은 Agent ID가 있으면 오류 안내 후 중단

### Step 2: 지속 학습 로드 (v5.0)

각 에이전트에 대해 `/Users/Claude/ProjectQA/_agent_learning/`에서 기존 학습을 로드합니다.

1. **도메인 지식 로드**: `_agent_learning/domain_experts/{domain}.md`가 존재하면 읽기
   - 비즈니스 규칙, 상태 머신, 경계값 패턴, 크로스 도메인 접점을 DKB 초기값으로 주입
2. **소스 전문성 참조**: `_agent_learning/source_specialists/*.md` 경로를 기록
   - Phase 1(`/팀소스분석`) 실행 시 서브에이전트 프롬프트에 주입될 예정
3. **TC 작성 스킬 참조**: `_agent_learning/tc_craft/*.md` 경로를 기록
   - Phase 2(`/팀TC생성`) 실행 시 서브에이전트 프롬프트에 주입될 예정
4. **팀 공유 메모리**: `_agent_learning/team_shared/workflow_lessons.md` 읽기
   - 과거 프로젝트 교훈을 현재 워크플로우에 반영

> **Override 규칙**: Layer 3(현재 프로젝트 DKB) > Layer 4(과거 학습). 현재 소스에서 확인된 사실이 과거 학습과 다르면 현재 소스가 우선합니다.

### Step 3: DKB 디렉토리 생성

각 선택된 에이전트에 대해 `_agents/{agent-id}/` 디렉토리와 DKB 템플릿 파일을 생성합니다.

```
_agents/{agent-id}/
├── service_profile.md      # 서비스 개요
├── business_rules.md       # 비즈니스 규칙
├── state_machines.md       # 상태 머신
├── dependencies.md         # 도메인 간 의존성
├── phase2_subagents.md     # Phase 2 서브에이전트 구성
└── domain_lens.md          # 소스 분석 시 도메인 렌즈 프롬프트
```

## 인자별 동작

### 기본 (에이전트 목록)
- 지정된 에이전트의 DKB 디렉토리 초기화
- 예: `/팀배포 funding,user,maker`

### all
- 15개 전체 에이전트 초기화
- 예: `/팀배포 all`

### fill:{agent-id}
- 지정 에이전트의 DKB를 ServiceKMS 기반으로 자동 채우기
- Atlassian MCP로 ServiceKMS 페이지를 분석하여 service_profile.md, business_rules.md 등 작성
- 예: `/팀배포 fill:funding`

### status
- 현재 투입된 에이전트와 DKB 채움 상태 보고
- 예: `/팀배포 status`

## 주의사항

- 이미 DKB가 존재하는 에이전트는 **덮어쓰지 않음** (기존 DKB 유지)
- DKB를 초기화하려면 해당 `_agents/{agent-id}/` 디렉토리를 수동 삭제 후 재실행
- Phase 2 서브에이전트 구성(phase2_subagents.md)은 매트릭스 생성 후 구체화하는 것을 권장
